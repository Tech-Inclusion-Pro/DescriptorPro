# Standards

`description_criteria.json` (Phase 3) holds the ten description criteria (DS-1 to
DS-10), their quoted sources, and the app behavior each one drives. The standards
view in the UI and the flag system both read from that one file, so what the user
sees is what the code applies (spec, section 6).

The file ships with `"quotes_verified": false` until every quotation is checked
line by line against its original document and Rocco confirms.
