# Prompts

Every model prompt used by Describe Studio lives here as a versioned text file,
named `<name>.v<version>.txt` (for example `describe.v1.txt`). The version used
for a run is written into the project's provenance record (spec, sections 3.3
and 11). Prompts are never embedded as string literals in code.

No prompts exist yet — they arrive with their pipeline stages (Phase 2+).
